Hangman (C++)
A console-based Hangman game written in C++. This project was created to practice C++ fundamentals including file input/output, vectors, functions, input validation, random number generation, and program organization.

Features
Current Features
Main menu system
Input validation for menu selections
Loads words from an external text file
Random word selection
Difficulty selection menu
Option to start a new game or exit
Planned Features
Letter guessing system
Hidden word display
Win/Loss conditions
Tracking guessed letters
Difficulty-based guess limits
Play again functionality

Technologies Used
C++
Visual Studio
Standard Template Library (STL)
vector
string
fstream

Clone the repository

Build and run the project
